# SourcePatch visual system

Operate mode. A quiet editorial repair desk with a persistent fixture warning, an inset Markdown source drawer, left citation queue, broad evidence pane and bottom export shelf. Inspection and explicit review are the primary rhythm. No decorative illustrations, third-party assets or remote fonts.

Tokens: canvas #f5f3ec, paper #fffef9, ink #202c26, muted #59625a, line #d9ddd2, forest #254d3b, forest tint #e5eee5, amber #765313, amber tint #f9edc8, red #8c3733. Body uses system sans; editorial titles Georgia serif; code ui-monospace. Spacing scale 4/8/12/16/24/32/48; 6px control corners; structural borders. Focus ring forest 3px with 3px offset. Reduced motion supported. Stacked layout below 760px.

Approving a choice transforms its queue row into a reviewed record. Export shows URL-only changes. No automatic approval or score-as-probability. Rendered browser verification remains outstanding.
