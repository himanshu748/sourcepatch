# Dedicated landing surface

Mode: Persuade. Audience: documentation maintainers with useful Markdown guides whose reference destinations have moved. Success: understand why a dead URL needs a reasoned review, inspect the honest fixture proof, then run the local workbench or inspect the repository.

This surface inherits the existing SourcePatch visual system in DESIGN.md. It does not replace the local application's Operate surface. Canvas #f5f3ec, paper #fffef9, forest #254d3b, ink #202c26; Georgia editorial titles, system sans body, monospace limited to URL/code/data. Structural rules and six-pixel controls follow the existing desk grammar. No remote assets, decorative illustration, or fonts.

First viewport: the product's exact promise, an immediate local-fixture CTA, and a real Python pathlib fixture showing the dead original destination, plausible replacement, and reasons that still need human judgment. The page's signature interaction is a searchable citation ledger generated by the real fixture engine. It exposes tied fetch scores, healthy and blocked destinations, source context, explicit limitations, and the query behind each result.

Scroll rhythm: spacious editorial introduction; denser evidence ledger; forest-backed URL-only patch and real exports; real labelled fixture video plus local launch instructions; concise evidence-status ledger. Source files are never modified by the landing. Candidate selection is inspection, not approval.

Verification budget: one batched desktop/mobile browser inspection, one batch of fixes if needed, at most one confirmation round. No live search, installs, publishing, or final submission. Parent performs independent review using the committed screenshots and receipt.
